# Acuerdo Lab

Actividad web sobre comunicación asertiva aplicada a la negociación de plazos y recursos en proyectos de software.

## Ejecutar

1. Abre una terminal en esta carpeta.
2. Ejecuta `npm start`.
3. Abre `http://localhost:3000`.

## Archivos principales

- `public/index.html`: página principal de la actividad.
- `public/admin.html`: panel para actualizar integrantes y evidencias.
- `server.js`: backend local sin dependencias externas.
- `data/site-data.json`: información del equipo y sus evidencias.
- `data/proposals.json`: propuestas creadas desde el simulador.

## Antes de entregar

Abre `http://localhost:3000/admin.html` y reemplaza los datos de ejemplo por los integrantes, las reflexiones y los enlaces reales de evidencias del grupo. El panel guarda los cambios en `data/site-data.json`.
